# KABLOCK!

A lightning-fast first-person voxel arena shooter where every wall is made of breakable blocks: slide, grapple and blast through storm-lit arenas, throw up instant cover, and outplay 7 clearly-labelled bots. Free, in your browser.

**Play:** https://riyaanb.github.io/kablock/

Part of [Loopwork Games](https://riyaanb.github.io/arcade/). MIT licensed. The game ships as a single `docs/index.html` (three.js and all code inlined; all art and audio generated at runtime). The hosted build uses cookieless GoatCounter analytics; see the [privacy page](https://riyaanb.github.io/arcade/privacy/).
